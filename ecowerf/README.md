# Ecowerf

Zet ophaaldata, saldo, tarieven en betalingen van mijnecowerf.be als sensoren in Home Assistant, via MQTT.

Vul na het installeren je gebruikersnaam en wachtwoord in op het tabblad Configuratie. Zie het tabblad Documentatie voor alle opties en sensoren, en het tabblad Changelog voor de wijzigingen per versie.
